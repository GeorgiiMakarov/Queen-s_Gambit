# engine-method

[![Selftest](https://github.com/GeorgiiMakarov/Queen-s_Gambit/actions/workflows/selftest.yml/badge.svg)](https://github.com/GeorgiiMakarov/Queen-s_Gambit/actions/workflows/selftest.yml)

Метод, вынесенный из маджонг-движка `danger_ev`, применённый к шахматам.
**Сам движок в шахматы не переносится, переносится только метод.**

## Идея

Переносится метод проверок (холдаут, интервалы, калибровка, селфтест). Самое
ценное в нём привычка, которую он закрепляет: сравнивать себя с сильными
людьми по реальным партиям, а не с идеальным ответом. В шахматах для этого
есть свободная база Lichess без ограничений Tenhou.

## Структура

```
common/    общий модуль проверок: холдаут, интервалы и калибровка (stats.py),
           симулятор для проверки статистики, общие векторы для JS (golden/)
chess/     тренажёр тактики для шахматистов (консоль и веб-версия)
mahjong/   замороженный движок v0.4.1 (не менять без решения Георгия)
docs/      план пилота и черновик питча
```

## Метод (common/)

1. **Холдаут**: случайный сплит по хешу ключа (как logs/logs2), с одинаковым
   распределением в train и test. Сплит по рейтингу/сложности не холдаут.
   Метка считается точным целым md5 mod 1000 (`split_label`), JS повторяет её
   поразрядно, совпадение проверяют общие векторы.
2. **Калибровка**: смещение (средняя уверенность минус точность) с z-критерием,
   интервалы Уилсона, Brier, навык log-loss против константного прогноза и
   вердикт (`common/stats.py`). Вердикт о самоуверенности только при n >= 30.
3. **Таблица опасности**: только тактические мотивы (служебные теги вроде фазы
   и длины исключены), прогноз по Glicko, остатки центрируются по длине задачи,
   усадка между темами. Флаг СЛАБО при n >= 20, z <= -3 и разрыве после усадки
   не меньше 5 п.п. На малых выборках флагов нет: это размер выборки, а не
   поломка (`tasks_for_gap`, `mde`).
4. **Селфтест**: проверки формата, легальности, сплита, решателя (N/N), плюс
   симуляция с известной правдой (`common/simulate.py`): ложные тревоги,
   мощность, эффект отбора.
5. **Честность к отрицательным результатам**: на test не лучше, не включаем,
   даже когда идея красивая. Слабую тему выбирают на одной половине базы, а
   меряют на другой (`select_and_evaluate`): иначе регрессия к среднему
   засчитывается за обучение.

## Маджонг (закрыт)

`mahjong/danger_ev.v041_frozen.py` — оценка опасности сброса под риичи.
Placement на оорасу: 51,2% vs 52,7% у очков, не побил, выключен.
На 412 ситуациях заметна лишь разница около 10 п.п., так что честная формулировка
«не доказано», а не «не помогает».
Логи Tenhou в репо не кладутся (только `check_logs.py`).

## Шахматы

Тренажёр тактики для шахматистов-спортсменов. Показывает задачу, фиксирует
ход, уверенность в процентах, время и итог. Рейтинг и темы задачи
показываются только после ответа. Рейтинг игрока берётся по нику из API
Lichess.

- `chess/trainer.py`: консольный тренажёр
- `chess/session.py`: логика сессии без python-chess (схема лога, выбор непройденных задач, отчёт)
- `chess/index.html`: веб-версия, один файл, лог в localStorage
- `chess/pilot_analysis.py`: честная оценка пилота до и после
- `chess/sim_false_alarms.py`: воспроизводит числа аудита на реальной выборке
- `chess/chess_tactics.py`: harness (8 ручных задач, холдаут, селфтест)
- `chess/sample_lichess.py` и `chess/puzzles_sample.csv`: выборка задач из базы Lichess
- `docs/pilot-plan.md`, `docs/pitch-one-pager.md`: план пилота и черновик питча

Запуск:

```
pip install python-chess
python3 chess/trainer.py --user НИК --n 10
python3 chess/trainer.py --report --user НИК
```

Дальше: партии спортсменов по нику, затем Maia (сверка с людьми нужного
рейтинга; базовая Maia покрывает рейтинги Lichess 1100-1900). Сама Maia
распространяется под GPL-3.0 и в репозиторий не входит.
