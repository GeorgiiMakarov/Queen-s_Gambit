# engine-method

[![Selftest](https://github.com/GeorgiiMakarov/Queen-s_Gambit/actions/workflows/selftest.yml/badge.svg)](https://github.com/GeorgiiMakarov/Queen-s_Gambit/actions/workflows/selftest.yml)

Метод, вынесенный из маджонг-движка `danger_ev`, применённый к шахматам.
**Сам движок в шахматы не переносится — переносится только метод.**

## Идея

Сам движок в шахматы не переносится — переносится метод проверок
(холдаут, log-loss, селфтест). А самое ценное в этом методе — привычка,
которую он закрепляет: сравнивать себя с сильными людьми по реальным
партиям, а не с идеальным ответом.
В шахматах для этого есть свободная база Lichess без ограничений Tenhou.

## Структура

```
common/    — общий модуль проверок: холдаут, log-loss, селфтест
mahjong/   — замороженный движок v0.4.1 (не менять без решения Георгия)
chess/     — шахматный тренажёр тактики (задачи решает человек)
```

## Метод (common/)

1. **Холдаут** — случайный сплит по хешу ключа (как logs/logs2), с одинаковым
   распределением в train и test. Сплит по рейтингу/сложности — не холдаут.
2. **Калибровка** — log-loss уверенности + ожидаемый шанс по Glicko-логисте.
   Темы, где факт хуже прогноза, — таблица опасности.
3. **Селфтест** — проверки формата, легальности, сплита, решателя (N/N).
4. **Честность к отрицательным результатам** — на test не лучше, не включаем,
   даже когда идея красивая. Выводы — не раньше 100–200 задач.

`chess/trainer.py --user НИК --n 10` — тренажёр: задача, твой ход,
уверенность в %, время, итог. Дальше: твои партии по нику → Maia.
