# Шахматы — тренажёр тактики

Задачи решает **человек**, а не поиск. Stockfish на задачах ничего не даст —
он решит почти всё, а ещё один шахматный движок не цель.

## Что здесь

- `trainer.py` (пункт 3): показывает задачу, принимает ход (UCI) и уверенность
  в %, засекает время, записывает итог в `trainer_log.csv`. Рейтинг и темы
  задачи показываются только после ответа (флаг `--hints` включает их до ответа,
  такие строки в отчёт не идут). Каждая сессия берёт новые задачи, уже решённые
  повторяются только когда свежих не хватило. Рейтинг игрока берётся по нику из
  API Lichess (`perfs.puzzle.rating`).
- `session.py`: логика сессии без python-chess; схема лога (ts, user, session,
  hints и прежние поля), перенос старого лога с копией `.bak`, отчёт.
- `index.html`: веб-версия на тех же правилах. Паритет с Python по общим векторам.
- `pilot_analysis.py`: оценка «до/после» без регрессии к среднему.
- `sim_false_alarms.py`: ложные тревоги, мощность и эффект отбора на этой выборке.
- `chess_tactics.py` — harness: 8 ручных задач (холдаут 4+4), встроенный
  решатель (демо) или UCI-движок (`--engine`), метрики exact + winning.
- `sample_lichess.py` — скачать базу задач Lichess и нарезать выборку
  (2000 задач, стратификация по рейтингу).
- `puzzles_sample.csv` — выборка 2000 задач Lichess (открытая база).
- `puzzles_calc.csv` — пул для режима `calc` (300 задач, long/veryLong, Moves ≥ 6,
  рейтинг 700–1100, без пересечения с основной выборкой).
- `mcp_server.py` — тренажёр как MCP-инструмент (AI-ассистент читает лог и строит отчёт).

## Режимы (--mode)

- `classic` (по умолчанию) — один ход + уверенность в одной строке, без лимита.
- `intuition` — «Интуиция»: только первый ход, жёсткий лимит `--limit` (по умолчанию 10 с).
  Не успел — промах, уверенность = 0, пометка timeout. В mateIn1 засчитывается любой матующий ход.
- `calc` — «Расчёт»: вся линия вслепую, уверенность на линию. Мягкий лимит 180 с (только логируется).
  strict (вся линия) идёт в статистику, depth (глубина до первой ошибки) — в отчёт.

Режимы не смешиваются в одной калибровке: отчёт разделяет строки по `mode`
(как для `hints`). В ни одном режиме рейтинг и темы не показываются до ответа.
Профиль («какой режим слабее») — только при n ≥ 100 в каждом режиме.

```
python3 trainer.py --user НИК --n 10 --mode intuition --limit 10
python3 trainer.py --user НИК --n 10 --mode calc
python3 trainer.py --selftest   # селфтест режимов
```

## Запуск

```
python3 trainer.py --user НИК --n 10            # практика (train)
python3 trainer.py --user НИК --n 10 --set test # проверка на свежем сете
python3 trainer.py --report --user НИК          # отчёт по логу
python3 trainer.py --user НИК --n 10 --hints    # тренировка с подсказками
python3 pilot_analysis.py trainer_log.csv --user НИК --cutoff 2026-11-01
python3 chess_tactics.py --lichess puzzles_sample.csv --sample 50
```

## Калибровка

- Смещение (средняя уверенность минус точность) с z-критерием, интервалы Уилсона,
  Brier и навык log-loss против константного прогноза. Вердикт о самоуверенности
  при n >= 30; по симуляции самоуверенность в 15 п.п. находится в 97% сессий по 100 задач (ошибка симуляции около 2 п.п.).
- Ожидаемый шанс по Glicko-логисте от (рейтинг игрока минус рейтинг задачи).
- Таблица тем: только мотивы, остатки центрируются по длине задачи (ожидание
  Glicko описывает решение всей задачи, а тренажёр проверяет первый ход), усадка
  между темами. Флаг только при n >= 20 по теме, z <= -3 и разрыве после усадки не
  меньше 5 п.п. Сотни задач нужны для самых частых тем, тысячи для редких.
- Задачи берутся без учёта рейтинга игрока, поэтому у сильного игрока многие
  задачи слишком лёгкие и мало говорят о калибровке. Отбор по рейтингу не сделан.

## Формат задач Lichess

Позиция задачи = FEN + Moves[0] (setup-ход), решение = Moves[1:].
Проверено кодом, нелегальных решений 0 (в том числе тестом `test_web.js` на всех 2000 задачах).
Ограничения выборки: взяты первые 400 задач каждой корзины рейтинга в порядке файла,
а колонки RatingDeviation, NbPlays, Popularity не сохранены, поэтому отфильтровать задачи
с ненадёжным рейтингом по этой выборке нельзя. Тренажёр проверяет только первый ход.
