## Логи Tenhou — НЕ в репо

Сырые логи (800 XML игр Houou) в репозиторий не кладутся — они большие
и получены отдельно. Положи их сам:

```
mahjong/raw_logs/logs/*.xml    # 400 игр (train)
mahjong/raw_logs/logs2/*.xml   # 400 игр (test)
```

Проверка: `python3 check_logs.py` — посчитает файлы и сверит раскладку.
